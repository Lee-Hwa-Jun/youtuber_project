# 🎬 랭킹 쇼츠 · 영상 소스 수집 매니저

> "Ranking Funniest Dog Reactions to Vacuum Cleaners" 같은 **랭킹 쇼츠**를 만들기 위해
> 여러 플랫폼에서 클립을 찾고 → 후보를 기록하고 → 1~5위를 배치하는 도구입니다.

**파일 하나(`index.html`)면 끝입니다.** 설치도, 서버도, 인터넷 연결도 필요 없습니다.

---

## 🚀 1분 만에 시작하기

### 맥(Mac)
1. `index.html` 파일을 **더블클릭**합니다.
2. 기본 브라우저(Safari/Chrome)에서 앱이 바로 열립니다. 끝!

### 윈도우(Windows)
1. `index.html` 파일을 **더블클릭**합니다.
2. 브라우저가 열리지 않으면 파일을 **마우스 오른쪽 클릭 → 연결 프로그램 → Chrome(또는 Edge)** 을 선택하세요.

> 💡 **자주 쓸 거라면** 브라우저에서 열린 뒤 `Ctrl + D` (맥은 `⌘ + D`)로 즐겨찾기에 추가해 두세요.
> 다음부터는 즐겨찾기 클릭 한 번으로 열립니다.

### ⚠️ 시작하기 전에 꼭 알아야 할 것 3가지

| | 내용 |
|---|---|
| 💾 | 데이터는 **여러분 브라우저 안(localStorage)** 에만 저장됩니다. 서버로 가지 않으니 안전하지만, **브라우저 기록/데이터를 삭제하면 같이 지워집니다.** |
| 📤 | 그래서 작업이 끝나면 **설정 탭 → JSON 내보내기**로 백업 파일을 만들어 두세요. (드라이브·바탕화면 어디든 OK) |
| 🌐 | 브라우저마다 저장 공간이 따로입니다. Chrome에서 만든 데이터는 Safari에 안 보입니다. 기기·브라우저를 옮길 땐 **JSON 내보내기 → 가져오기**를 쓰세요. |

## 🗺 전체 작업 흐름 (이 순서대로만 하면 됩니다)

```
① 프로젝트 만들기        예: "Dog vs Vacuum"
        ↓
② 검색어 탭에서 클립 찾기  플랫폼 버튼 클릭 → 새 탭에서 영상 탐색
        ↓
③ 클립 DB 탭에 기록      URL 붙여넣기 + 웃긴 포인트 + 점수 + 라이선스
        ↓
④ 원작자에게 DM 보내기    사용 허락 요청 → 상태를 "DM 보냄"으로 변경
        ↓
⑤ 허락받으면 상태 변경     "허락받음"으로 바꾸면 랭킹 후보가 됩니다
        ↓
⑥ 랭킹 보드에서 배치      5위 → 1위 순서 결정 + 러닝타임 35~50초 맞추기
        ↓
⑦ 설정 탭에서 JSON 백업    안전한 곳에 보관
```

## 📑 탭별 사용법

### 📊 1. 대시보드 — 지금 어디까지 왔는지 한눈에

앱을 열면 가장 먼저 나오는 화면입니다. 직접 입력할 건 없고, **현황만 보여주는 곳**입니다.

| 보이는 것 | 의미 |
|---|---|
| **수집한 클립** | 목표(기본 25개) 대비 몇 개를 모았는지 |

| **랭킹 배치 / 평균 임팩트** | 5칸 중 몇 칸을 채웠는지, 클립들의 평균 별점 |

> 💡 답장 대기 알림은 라이선스를 「DM 보냄」으로 바꾼 **그날부터 자동으로 날짜를 셉니다.**

### 🔎 2. 검색어 — 클립 찾으러 가는 출발점

주제 키워드를 넣어두면, 버튼 한 번으로 각 플랫폼 검색 결과가 **새 탭**에서 열립니다.

**처음 열면 기본 검색어 7개가 이미 들어 있습니다:**
`dog scared of vacuum` / `dog vs vacuum cleaner` / `dog vacuum reaction` /
`dog afraid roomba` / `dog rides roomba` / `강아지 청소기` / `로봇청소기 강아지`

#### 검색어 추가하는 두 가지 방법
| 버튼 | 하는 일 |
|---|---|
| **＋ 그대로 추가** | 입력한 문장을 그대로 검색어 목록에 넣습니다 |
| **✨ 변형 자동 생성** | 입력한 키워드에 `reaction` `funny` `compilation` `scared` (한글이면 `반응` `웃긴` `모음` 등) 꼬리말을 붙여 **한 번에 6~8개**를 만듭니다 |

#### 검색어마다 붙는 플랫폼 버튼
| 버튼 | 열리는 곳 | 참고 |
|---|---|---|
| ▶️ **YouTube** | 유튜브 검색 결과 | **4분 미만 영상만** 자동 필터링 (쇼츠 소재로 적합) |
| 📱 **Shorts** | 검색어 + `#shorts` | 세로 영상 위주로 나옵니다 |
| 🎵 **TikTok** | 틱톡 검색 | |
| 📸 **Instagram** | 인스타그램 키워드 검색 | 로그인이 필요할 수 있습니다 |
| 👽 **Reddit** | 레딧 인기순 검색 | `r/aww`, `r/AnimalsBeingDerps` 등 원본이 많습니다 |
| 🖼 **역검색** | 구글 이미지 검색 | **원본 영상 추적용** (재업로드 계정을 걸러낼 때) |
| 🚀 **한번에 열기** | 주요 4개 플랫폼 동시에 | 브라우저가 팝업을 막으면 "허용"을 눌러주세요 |

> 💡 마음에 안 드는 검색어는 `✕`, 고치고 싶으면 `✎` 를 누르세요.
> **📋 전체 복사**를 누르면 검색어 전체가 클립보드에 복사됩니다.

### ▶️ 3. YouTube 검색 — 앱 안에서 바로 검색 (선택 기능)

**이 탭은 없어도 앱을 쓰는 데 아무 지장이 없습니다.** 검색어 탭의 링크 버튼으로도 충분합니다.
다만 API 키를 넣으면 **앱을 떠나지 않고** 검색하고, 결과를 버튼 한 번으로 클립 DB에 담을 수 있습니다.

#### API 키 무료로 받는 법 (5분)
1. [Google Cloud Console](https://console.cloud.google.com/) 에 구글 계정으로 접속합니다. **무료**입니다.
2. 상단에서 **새 프로젝트**를 만듭니다. (이름은 아무거나)
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용 설정**
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
5. 만들어진 키(`AIza...`로 시작)를 복사해 이 탭 또는 **설정 탭**에 붙여넣고 저장

> 🔒 키는 **내 브라우저에만** 저장되며 어떤 서버로도 전송되지 않습니다.
> JSON 백업 파일에도 **일부러 포함하지 않습니다.** (공용 PC에서 썼다면 설정 탭에서 삭제하세요)

#### 검색 조건
- 항상 **동영상 · 4분 미만(short) · 최대 25개**로 검색합니다
- **조회수순 / 최신순 / 관련도순**을 고를 수 있습니다
- 각 결과 카드에 **썸네일·제목·채널명·조회수·게시일·영상 길이**가 표시됩니다
- **＋ 클립 DB에 추가** 를 누르면 제목·채널·썸네일·길이가 자동으로 채워진 등록 창이 열립니다
- 이미 담은 영상은 **✅ 담김**으로 표시돼 중복 등록을 막아줍니다

> ⚠️ 하루 무료 할당량은 10,000유닛이고 검색 1회에 약 100유닛이 듭니다 → **하루 약 90회 검색 가능**.
> 다 쓰면 `quotaExceeded` 오류가 나며, 다음 날 자정(태평양 시간)에 초기화됩니다.

> 🛡 **TikTok·Instagram 자동 수집은 지원하지 않습니다.** 각 사의 이용약관과 브라우저 보안(CORS) 정책 때문입니다.
> 검색 링크로 직접 확인한 뒤 클립 DB에 수동 등록하세요.

### 🎞 4. 클립 DB — **이 앱의 핵심**

찾은 영상을 기록해 두는 곳입니다. 여기에 잘 적어두면 편집할 때 시간이 훨씬 절약됩니다.

#### 등록하는 가장 빠른 방법
1. 영상 페이지에서 **주소창 URL을 복사**합니다
2. **빠른 등록** 칸에 붙여넣고 `Enter` → 등록 창이 열립니다
3. 플랫폼은 **자동 감지**되고, 유튜브면 **썸네일도 자동**으로 붙습니다

#### 입력 항목
| 항목 | 설명 | 꼭 필요? |
|---|---|---|
| **영상 URL** | 붙여넣기만 하면 플랫폼·썸네일 자동 인식 | ✅ |
| **제목** | 나중에 알아보기 쉬운 이름 | 선택 |
| **원작자 계정** | `@닉네임`. **DM 보낼 때 꼭 필요하니 반드시 적어두세요** | ⭐ 중요 |
| **웃긴 포인트** | 예: *"청소기 켜자마자 뒤로 1미터 점프 + 소파 뒤로 숨음"* | ⭐ 중요 |
| **카테고리** | 무서워하는 반응 / 맞서 싸우는 반응 / 반전·의외의 반응 | ✅ |
| **클립 길이(초)** | 실제로 쓸 구간의 길이. 랭킹 러닝타임 계산에 쓰입니다 | 선택 |
| **임팩트 점수 ★1~5** | 얼마나 웃긴지. **랭킹 순서를 정하는 기준** | ✅ |
| **라이선스 상태** | 아래 표 참고 | ⭐ 중요 |

#### 라이선스 상태 6단계 (색으로 구분됩니다)
| 뱃지 | 상태 | 의미 |
|---|---|---|
| ⚪ 회색 | **미확인** | 아직 아무 연락도 안 함 (기본값) |
| ✉️ 노랑 | **DM 보냄** | 사용 허락을 요청함 → 7일 지나면 대시보드가 알려줍니다 |
| ✅ **초록** | **허락받음** | 원작자가 승낙 → **랭킹 보드에 올라갑니다** |
| 🅭 파랑 | **CC·퍼블릭도메인** | 자유 이용 라이선스 → **랭킹 보드에 올라갑니다** |
| 💳 보라 | **라이선스 구매** | 스톡 영상 등 유료 구매 → **랭킹 보드에 올라갑니다** |
| ⛔ **빨강** | **사용불가** | 거절당했거나 쓸 수 없음 |

#### 목록에서 할 수 있는 일
- 🔍 **검색** — 제목·메모·계정·URL을 한 번에 검색
- **필터** — 카테고리별 / 라이선스 상태별로 추리기
- **정렬** — 등록일순 · 임팩트 점수순 · 라이선스 상태순 · 조회수순 (표 머리글 클릭으로도 정렬)
- 각 줄의 버튼 — `↗` 영상 열기 · `🖼` 이미지 역검색(원본 추적) · `✎` 수정 · `🗑` 삭제
- **⬇ CSV 내보내기** — 엑셀·구글 시트에서 바로 열리는 표로 저장 (한글 안 깨짐)

> ⚖️ **저작권은 꼭 지켜주세요.** 다른 사람의 영상은 원작자 허락 없이 쓸 수 없습니다.
> 인스타·틱톡 DM이나 유튜브 채널 문의로 사용 허락을 받고, 영상에 **출처(@계정명)를 표기**하는 것이 기본 매너입니다.

### 🏆 5. 랭킹 보드 — 5위부터 1위까지 배치

**허락받음 / CC·퍼블릭도메인 / 라이선스 구매** 상태인 클립만 후보로 올라옵니다.
(→ 후보가 안 보인다면 클립 DB에서 라이선스 상태를 먼저 바꿔주세요)

#### 배치하는 두 가지 방법
| 기기 | 방법 |
|---|---|
| **PC** | 오른쪽 후보 클립을 **드래그해서** 원하는 슬롯에 **놓기** |
| **모바일/태블릿** | 후보를 **한 번 탭**(선택됨) → 배치할 **슬롯을 탭** |

**✨ 점수순 자동 배치** 버튼을 누르면 임팩트 점수가 높은 순으로 1~5위를 한 번에 채웁니다.
(자동 배치 후 마음에 안 드는 부분만 손으로 바꾸는 방식을 추천합니다)

#### 각 슬롯의 권장 가이드
| 순위 | 어떤 클립을 넣을까 |
|---|---|
| **5위** | 무난하지만 확실한 웃음. 오프닝이라 짧고 바로 이해되는 클립 |
| **4위** | 리액션이 한 단계 더 큰 클립. "다음은?" 기대하게 만들기 |
| **3위** | 중간 텐션 유지. 앞뒤와 **다른 카테고리**를 넣어 지루함 끊기 |
| **2위** | 임팩트 최상위권. 1위 직전 텐션 최대로 |
| **1위** | **최고 임팩트 또는 반전.** 가장 강한 웃음이나 예상 밖 결말 |

#### 러닝타임 맞추기
- 각 슬롯의 **「초」 칸**에 그 클립을 몇 초 쓸지 적으면 **자동으로 합산**됩니다
- **35~50초**가 쇼츠 시청 유지율에 가장 유리합니다
  - 🟡 35초 미만 → *"권장보다 짧습니다"*
  - 🟢 35~50초 → *"권장 안에 들어왔습니다 👍"*
  - 🔴 50초 초과 → *"권장보다 깁니다 — 더 짧게 잘라보세요"*

### ⚙️ 6. 설정 — 프로젝트·백업 관리

#### 프로젝트 설정
- **영상 제목(프로젝트 이름)** 바꾸기
- **목표 클립 수** 바꾸기 (기본 25개)
- **카테고리** 편집 — 한 줄에 하나씩 적으면 됩니다
  *(카테고리를 지우면 그 카테고리였던 클립은 첫 번째 카테고리로 자동 이동합니다)*
- **＋ 새 프로젝트 / ⧉ 복제 / 🗑 삭제**
  - **복제**는 비슷한 주제로 2편을 만들 때 유용합니다 (검색어·카테고리 설정이 그대로 복사됩니다)

#### 백업 · 이동 ⭐
| 버튼 | 결과 파일 | 용도 |
|---|---|---|
| **⬇ 전체 JSON 내보내기** | `ranking-shorts-backup-날짜.json` | **완전 백업.** 모든 프로젝트·클립·랭킹 포함 |
| **⬇ 클립 DB CSV 내보내기** | `clips-db-....csv` | 엑셀·구글 시트에서 열어보기 |
| **⬆ JSON 가져오기** | | 백업 복원 / 다른 기기에서 이어서 작업 |

**가져오기를 누르면 선택 창이 뜹니다:**
- **[확인]** → 현재 데이터를 모두 지우고 **덮어쓰기** (다른 기기로 옮길 때)
- **[취소]** → 기존 데이터는 두고 **프로젝트만 추가** (합칠 때)

> 🔄 **다른 컴퓨터로 옮기는 법**
> ① 기존 PC에서 **JSON 내보내기** → ② `index.html` 과 `.json` 파일을 USB·드라이브로 옮기기

## ❓ 자주 묻는 질문

<details>
<summary><b>인터넷이 없어도 되나요?</b></summary>

네, 앱 자체는 오프라인에서도 완전히 동작합니다.
다만 ① 검색 링크 열기 ② YouTube 자동 검색 ③ 유튜브 썸네일 표시는 인터넷이 필요합니다.
(썸네일이 안 보이면 플랫폼 아이콘이 대신 표시됩니다)
</details>

<details>
<summary><b>파일을 더블클릭했더니 메모장/코드 편집기가 열려요</b></summary>

`index.html` 을 **마우스 오른쪽 클릭 → 연결 프로그램 → Chrome / Edge / Safari** 를 선택하세요.
"항상 이 앱으로 열기"에 체크해 두면 다음부터는 더블클릭만으로 열립니다.
</details>

<details>
<summary><b>"한번에 열기"를 눌렀는데 탭이 안 열려요</b></summary>

브라우저의 **팝업 차단** 기능 때문입니다. 주소창 오른쪽에 뜨는 차단 아이콘을 눌러
**"항상 허용"** 을 선택하세요.
</details>

<details>
<summary><b>데이터가 갑자기 사라졌어요</b></summary>

브라우저 데이터(쿠키·사이트 데이터)를 삭제했거나, 시크릿/프라이빗 창에서 사용했을 가능성이 큽니다.
시크릿 창은 창을 닫는 순간 데이터가 사라집니다. **일반 창**에서 사용하고, 주기적으로 JSON 백업을 하세요.
</details>

<details>
<summary><b>랭킹 보드에 후보가 하나도 안 보여요</b></summary>

랭킹 보드에는 **라이선스가 확보된 클립만** 올라옵니다.
클립 DB에서 해당 클립의 라이선스 상태를 **허락받음 / CC·퍼블릭도메인 / 라이선스 구매** 중 하나로 바꿔주세요.
</details>

<details>
<summary><b>CSV 파일이 엑셀에서 한글이 깨져요</b></summary>

깨지지 않도록 BOM을 넣어 저장합니다. 그래도 깨진다면 엑셀에서
**데이터 → 텍스트/CSV 가져오기 → 원본 파일: UTF-8** 로 여세요.
(구글 시트에서는 그냥 열어도 정상입니다)
</details>

<details>
<summary><b>내보낸 파일 이름이 영어인데 왜 그런가요?</b></summary>

파일을 `file://` 로 열었을 때 크롬이 한글 파일명을 무시하고 확장자 없는 `download` 로 저장해 버립니다.
그래서 **파일 이름만 영어**로 만들고, 파일 안의 한글 데이터는 그대로 유지합니다. 저장 후 마음대로 바꾸셔도 됩니다.
</details>

<details>
<summary><b>API 키를 넣는 게 안전한가요?</b></summary>

키는 브라우저 localStorage에만 저장되고 어떤 서버로도 전송되지 않으며, JSON 백업에도 포함되지 않습니다.
그래도 걱정된다면 Google Cloud Console에서 그 키에 **YouTube Data API v3만 허용**하도록 제한을 걸어두세요.
공용 PC에서 썼다면 설정 탭에서 삭제하고 나오세요.
</details>
