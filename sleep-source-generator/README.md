# 🌌 소스 생성기 — 수면 주파수 영상용

수면·명상 주파수 영상을 만들 때 쓰는 **소스 뽑기 도구**입니다.
몽환적인 무한 루프 영상(webm)과 주파수 음원(wav)을 **각각 따로** 만들어 내려받고,
최종 합치기·자막·편집은 외부 편집기(프리미어, 다빈치 리졸브, 캡컷 등)에서 합니다.

파일 하나(`source-gen.html`)면 끝입니다. 설치·서버·빌드 없이 더블클릭으로 열립니다.

---

## 🚀 시작하기

1. `source-gen.html` 더블클릭 → 브라우저에서 열림 (**Chrome 또는 Edge 권장** — 영상 녹화 기능 때문)
2. **비주얼 생성기** 탭에서 영상 소스를 녹화해 webm 으로 저장
3. **주파수 음원 생성기** 탭에서 음원을 wav 로 저장
4. 편집기에 둘을 넣고 길이를 맞춰 합치기

> 두 소스는 길이가 서로 다른 게 정상입니다. 영상은 1~5분짜리 **완벽 루프**라 편집기에서 여러 번 이어붙이고,
> 음원은 10~60분짜리를 한 번에 깔면 됩니다.

## 🌌 탭 1 · 비주얼 생성기

### 패턴 6종

| 패턴 | 느낌 | 기본 주기 |
|---|---|---|
| 네뷸라 | 보라·남색 성운이 천천히 유영 | 60초 |
| 별밭 | 은은히 깜빡이는 별 + 가끔 유성 | 90초 |
| 숨쉬는 원 | 중앙에서 팽창·수축하는 동심원 (호흡 유도) | 호흡 주기 × N |
| 오로라 | 화면 하단에서 일렁이는 빛 커튼 | 48초 |
| 유체 연기 | 어두운 연기 결이 흐르듯 | 60초 |
| 반딧불 | 어둠 속을 부유하는 흐릿한 빛 입자 | 60초 |

숨쉬는 원은 **호흡 주기 슬라이더**(3~12초)가 따로 있습니다. 들숨+날숨 한 번의 길이입니다.

### 공통 슬라이더

| 슬라이더 | 뜻 |
|---|---|
| 속도 | 0.25×~3×. 주기를 나눕니다 (2× 면 주기가 절반) |
| 밀도 | 요소 개수 (성운 겹 수, 별 개수, 링 수 …) |
| 글로우 | 빛 번짐·밝기 |
| 배경 밝기 | 0 = 순수 검정, 올릴수록 팔레트 색이 아주 어둡게 깔림 |
| 색상 팔레트 | 남색 / 보라 / 청록 / 앰버 / 모노 |

### 완벽 루프가 되는 이유 (중요)

모든 애니메이션은 **주기(period) 하나의 위상 t∈[0,1)** 로만 그려지고, 시간에 곱하는 계수는 전부 **정수**입니다.
그래서 주기 P초의 마지막 프레임 다음이 첫 프레임과 정확히 이어집니다.

녹화 길이는 **주기의 정수배로 자동 스냅**됩니다. 화면에 이렇게 표시됩니다:

```
요청 1분 → 실제 60.0초 = 주기 60.0초 × 1회
요청 3분 → 실제 189.0초 = 주기 63.0초 × 3회   ← 스냅됨
```

스냅된 길이로 녹화하면 편집기에서 같은 파일을 여러 번 이어붙여도 이음새가 보이지 않습니다.

### 녹화

| 설정 | 선택지 |
|---|---|
| 해상도 | 1920×1080 (FHD) / 3840×2160 (4K) / 1080×1920 (세로) |
| 프레임 | 30 / 60 fps |
| 비트레이트 | 8 / 12 / 16 / 24 / 32 Mbps (기본 16) |
| 길이 | 10초 / 30초 / 1분 / 3분 / 5분 → 주기 정수배로 스냅 |

- **녹화 시작**을 누르면 실시간으로 녹화됩니다 (1분 녹화 = 1분 소요). 끝나면 저장 대화상자가 뜹니다.
- 녹화 중에는 모든 파라미터와 탭이 **잠깁니다**. 취소 버튼으로 중단할 수 있습니다.
- 파일명: `visual_네뷸라_1920x1080_30fps_60s.webm` 형식
- **정지 이미지 PNG** 버튼으로 현재 프레임을 썸네일용으로 저장할 수 있습니다.

> ⚠️ **녹화 중 탭을 벗어나지 마세요.** 브라우저는 보이지 않는 탭의 화면 갱신을 멈추기 때문에
> 프레임이 끊기거나 길이가 늘어납니다. 탭이 비활성화되면 경고 배너가 뜨고, 완료 시에도 다시 알려줍니다.
> 그 녹화는 다시 하는 것을 권합니다.

> 💡 **4K 는 30fps 를 권합니다.** 4K·60fps 는 컴퓨터 성능에 따라 프레임이 떨어질 수 있습니다.
> 예상 용량은 화면에 표시됩니다 (16Mbps × 1분 ≈ 120MB).

## 🎧 탭 2 · 주파수 음원 생성기

Hz 를 입력해 항목을 추가하고, **항목마다 따로 설정하고 따로 내려받습니다.**
자주 쓰는 값(174 · 285 · 396 · 417 · 432 · 528 · 639 · 741 · 852 · 963 Hz)은 칩으로 바로 추가됩니다.

### 모드 3종

| 모드 | 설명 | 필드 |
|---|---|---|
| 퓨어 톤 | 단일 사인파 | 주파수 |
| 바이노럴 비트 | 왼쪽 = 캐리어, 오른쪽 = 캐리어 + 비트. 좌우 차이로 뇌파 리듬을 만듭니다. **이어폰 필수** | 캐리어(Hz), 비트(Hz) |
| 톤 + 노이즈 | 사인파에 핑크/브라운 노이즈를 섞음 | 주파수, 노이즈 종류, 비율 |

바이노럴 비트 참고: 델타 1–4Hz(깊은 수면) · 세타 4–8Hz(얕은 수면·명상) · 알파 8–13Hz(이완).
예: 캐리어 200Hz + 비트 4Hz → 왼쪽 200Hz / 오른쪽 204Hz.

### 공통 설정

| 설정 | 범위 | 기본 |
|---|---|---|
| 길이 | 1 / 3 / 5 / 10 / 15 / 20 / 30 / 45 / 60분 | 10분 |
| 볼륨 | −40 ~ 0 dBFS | −12 dBFS |
| 페이드인 / 페이드아웃 | 0 ~ 60초 | 3초 |

**dBFS** 는 디지털 최대 레벨 기준입니다. 0 dBFS 가 최대, −12 dBFS 는 약 25% 진폭입니다.
수면용은 −12 ~ −18 정도가 무난하고, 편집기에서 다시 조절할 여지를 두는 게 좋습니다.
어떤 모드든 **피크가 설정한 볼륨을 넘지 않도록** 만들어져 클리핑이 없습니다.

### 미리듣기
▶ 버튼으로 실시간 재생됩니다(페이드인 적용). 재생 중 볼륨 슬라이더를 움직이면 바로 반영되고, ■ 로 멈춥니다.

### WAV 생성
- **44.1kHz · 16bit · 스테레오** WAV 로 저장됩니다.
- 파일명에 주파수·모드·길이가 들어갑니다:
  `tone_432Hz_10min.wav` · `binaural_200Hz_4Hz_30min.wav` · `mix_528Hz_pink30_15min.wav`
  (소수 Hz 는 `432p5Hz` 처럼 점을 p 로 씁니다)
- 항목 아래 **상태 줄**에 실제 길이(초), 총 사이클 수, 예상 파일 크기(분당 약 10.6MB)가 미리 표시됩니다.

### 클릭 노이즈가 없는 이유

사인파는 **위상 0 에서 시작**하고, 샘플 수는 `주파수 × 길이` 가 **정확히 정수 사이클**이 되도록 고릅니다
(정수 Hz·정수 초면 그대로, 소수 Hz 면 ±1초 안에서 맞춥니다).
그래서 파일의 끝 다음에 같은 파일의 시작을 붙이면 사인파가 그냥 이어집니다 — 클릭이 나지 않습니다.
바이노럴은 좌우 두 주파수 모두 정수 사이클이 되게 맞춥니다.

> 참고로 끝 샘플의 값 자체는 정확히 0 이 아니라 "다음 주기의 0 바로 직전" 입니다. 그게 맞는 겁니다 —
> 끝을 억지로 0 으로 만들면 이어붙일 때 0 이 두 번 연속되어 오히려 미세한 흠이 생깁니다.

### 긴 파일 (30분 이상)

브라우저 안에서 만들기 때문에 메모리 한계가 있습니다. 60분 스테레오 WAV 는 약 635MB 입니다.

- 렌더링은 **5분 단위로 나눠** 진행되고 진행률이 표시됩니다.
- 나누는 경계도 **정수 사이클 위치**라 구간 사이에 이음새가 없습니다.
- 30분 이상 선택하면 주의 안내가 뜹니다. **실패하면** 길이를 절반으로 나눠(60분 → 30분 × 2) 따로 만든 뒤
  편집기에서 이어붙이세요. 같은 설정이면 파일 경계에서 위상이 0 이라 클릭이 없습니다.

## 🎬 편집기에서 합치기 팁

1. 음원(wav)을 타임라인에 먼저 놓고 전체 길이를 정합니다.
2. 영상(webm)을 그 위에 놓고, **같은 클립을 복사해 끝까지 이어붙입니다.** 스냅된 길이라 이음새가 없습니다.
3. 마지막 클립은 음원 길이에 맞춰 자르고, 영상·음원 모두 끝에 페이드아웃을 줍니다.
4. 썸네일은 **정지 이미지 PNG** 를 쓰거나 편집기에서 프레임을 뽑습니다.

> webm 을 읽지 못하는 편집기(구버전 프리미어 등)라면 HandBrake 같은 무료 도구로 mp4 로 바꿔 넣으세요.
> 브라우저 안에서는 mp4 로 직접 녹화할 수 없어서 webm 으로 뽑습니다.

## ❓ 자주 묻는 질문

**Q. 녹화 버튼을 눌러도 아무 일이 없어요 / "지원하지 않는 브라우저" 가 떠요**
Safari 와 일부 브라우저는 캔버스 녹화(MediaRecorder)를 지원하지 않거나 불완전합니다. **Chrome 또는 Edge** 에서 여세요.

**Q. 녹화한 영상이 끊기거나 길이가 이상해요**
녹화 중 다른 탭이나 창으로 갔을 가능성이 큽니다. 브라우저가 화면 갱신을 멈추기 때문입니다.
녹화 중에는 이 탭을 그대로 두세요. 4K·60fps 라면 30fps 로 낮춰보세요.

**Q. 편집기에서 이어붙였는데 이음새가 살짝 보여요**
녹화 길이가 스냅된 값(화면의 "실제 N초")과 같은지 확인하세요. 편집기에서 클립을 자르지 말고 **원본 길이 그대로** 이어붙여야 합니다.

**Q. 미리듣기 소리가 안 나요**
브라우저 자동재생 정책 때문에 페이지를 클릭한 뒤에야 소리가 납니다. ▶ 버튼을 다시 누르세요.

**Q. 60분 WAV 생성이 실패해요**
브라우저 메모리 한계입니다. 30분 × 2 로 나눠 만들고 편집기에서 이어붙이세요 (클릭 없음).

**Q. mp3 로는 안 되나요**
브라우저 안에서 외부 라이브러리 없이 mp3 인코딩은 어렵습니다. wav 로 뽑아 편집기에서 내보낼 때 원하는 형식으로 바꾸세요. 어차피 최종 영상에 합쳐지므로 wav 가 음질도 낫습니다.

## 🛠 고칠 곳 (유지보수)

| 위치 | 뜻 |
|---|---|
| `PATTERNS` | 패턴 이름·설명·기본 주기(초) |
| `PALETTES` | 팔레트별 배경색과 3가지 강조색 (RGB) |
| `RESOLUTIONS`, `DURATIONS` | 해상도·녹화 길이 선택지 |
| `DUR_MIN`, `SOLFEGGIO` | 음원 길이 선택지·자주 쓰는 Hz 칩 |
| `SR` | 샘플레이트 (44100) |
| `CHUNK_TARGET_SEC` | 긴 파일을 나눠 렌더링하는 단위 (기본 300초) |

새 패턴을 추가하려면 `drawXxx(ctx, W, H, t)` 함수를 만들고 `DRAW` 와 `PATTERNS` 에 등록하면 됩니다.
**시간 t 에 곱하는 계수는 반드시 정수**로 두세요 — 그래야 루프가 유지됩니다.

## 🧰 기술 정보

| 항목 | 내용 |
|---|---|
| 구성 | `source-gen.html` 단일 파일 (HTML + CSS + JS) |
| 의존성 | 없음. 외부 라이브러리·폰트·CDN 없음 |
| 영상 | Canvas 2D + `captureStream` + `MediaRecorder` → webm (VP9, 미지원 시 VP8) |
| 음원 | Web Audio `OfflineAudioContext` 렌더링 → 직접 구현한 WAV 인코더 (RIFF/PCM 16bit) |
| 저장 | 모두 Blob URL → 브라우저 저장 대화상자. 서버 전송 없음 |
| 지원 브라우저 | Chrome · Edge 최신 (녹화 기능). 음원만이라면 Safari·Firefox 도 가능 |
| 유체 연기 성능 | 192px 폭 작업 캔버스에 그린 뒤 확대 — 4K 에서도 가벼움 |
