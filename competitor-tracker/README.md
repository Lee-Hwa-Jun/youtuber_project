# 📈 경쟁 채널 트래커

경쟁 유튜브 쇼츠 채널을 등록해 두고 **주기적으로 조회수 스냅샷을 찍어서**,
지금 어떤 주제·제목의 쇼츠가 빠르게 크고 있는지 발견하는 벤치마킹 도구입니다.

```
같은 영상을 하루 두 번 찍으면 →  100,000회 (아침)  →  160,000회 (저녁)
                                  = 시간당 5,000회  ← "지금 터지는 중"
```

**파일 하나(`tracker.html`)면 끝입니다.** 설치도, 서버도, 빌드도 없습니다.

---

## 🚀 시작하기

### 1. 실행
`tracker.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. (Mac / Windows 공통)
열리지 않으면 파일을 **오른쪽 클릭 → 연결 프로그램 → Chrome / Edge / Safari**.

### 2. API 키 발급 (무료, 5분)
이 도구는 YouTube Data API v3로 데이터를 가져오므로 키가 **반드시** 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/) 에 구글 계정으로 접속합니다.
2. 상단에서 **새 프로젝트**를 만듭니다. (이름은 아무거나)
3. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용 설정**
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
5. 만들어진 키(`AIza...`)를 복사해 **설정 탭**에 붙여넣고 저장

> 🔒 키는 이 브라우저(localStorage)에만 저장되고 어떤 서버로도 전송되지 않습니다.
> JSON 백업 파일에도 **일부러 포함하지 않습니다.**

### 3. 채널 등록 → 새로고침
1. **채널 탭**에서 경쟁 채널 주소를 붙여넣고 등록 (10~20개 권장)
2. **전체 새로고침** — 각 채널의 최신 쇼츠와 현재 조회수를 저장 (스냅샷 1개)
3. **몇 시간 뒤 다시 새로고침** — 스냅샷이 2개 되면 **증가 속도**가 계산됩니다
4. **급상승 탭**에서 빠르게 크는 영상을 확인

> 💡 하루 1~2번씩만 눌러 주면 충분합니다. 자동 폴링은 일부러 넣지 않았습니다.

## ⚡ 쿼터(할당량) 이야기 — 이 도구의 설계 핵심

YouTube API는 **하루 10,000유닛** 무료로 주고, 호출마다 비용이 다릅니다.

| 호출 | 비용 | 이 도구에서 |
|---|---|---|
| `search.list` | **100유닛** | ❌ **아예 쓰지 않습니다** |
| `channels.list` | 1유닛 | 채널 등록·구독자 갱신 |
| `playlistItems.list` | 1유닛 | 업로드 목록에서 영상 ID 수집 |
| `videos.list` | 1유닛 | 영상 50개씩 묶어서 상세 조회 |

검색 API 한 번이면 채널 50개를 새로고침할 수 있습니다. 그래서 이 도구는
채널의 **업로드 재생목록**을 직접 읽는 방식만 씁니다.

### 실제 비용
```
채널 1개 새로고침 = 2유닛  (playlistItems 1 + videos 1)
채널 20개 전체 새로고침 = 1 + 2×20 = 41유닛
→ 하루 10,000유닛이면 전체 새로고침을 약 240번 할 수 있습니다
```

화면 맨 아래 **쿼터 바**에 오늘 사용한 예상 유닛과 잔여량이 항상 표시됩니다.
남은 양보다 예상 사용량이 많으면 새로고침 전에 막고 알려줍니다.

> ⏰ **리셋은 태평양 시간(PT) 자정**입니다. 한국 시간으로는 오후 4시(서머타임 때는 오후 5시)쯤입니다.
> 쿼터 바에 "약 N시간 후 리셋"으로 표시됩니다.

> ⚠️ 이 숫자는 **예상치**입니다. 실제 사용량은 Google Cloud Console →
> API 및 서비스 → 할당량에서 확인하세요. (재시도·오류 응답도 쿼터를 소모합니다)

## 📑 탭별 사용법

### 🚀 급상승 — 메인 화면
등록한 모든 채널의 쇼츠를 **조회수 증가 속도순**으로 줄 세웁니다.

| 항목 | 설명 |
|---|---|
| **시간당 조회수** | 이 도구의 핵심 지표. 클수록 지금 빠르게 크는 중 |
| **추이** | 스냅샷을 이은 미니 그래프. 마우스를 올리면 최초·최근 값이 나옵니다 |
| **📋 소스 수집** | 제목을 클립보드에 복사 (소스 수집 매니저에 붙여넣기용) |

**속도를 어떻게 계산하나요?**
- 스냅샷이 2개 이상이면 → `(최근 조회수 − 이전 조회수) ÷ 경과 시간`
- 스냅샷이 1개뿐인 새 영상이면 → `총 조회수 ÷ 게시 후 경과 시간`
- 표에 **어느 방식으로 계산했는지** 항상 같이 표시됩니다.

> 🔎 연속으로 새로고침하면 두 스냅샷 간격이 너무 짧아 증가분이 0에 수렴합니다.
> 그래서 **10분 이상 떨어진** 이전 스냅샷을 거슬러 찾아서 계산합니다.

**필터**: 특정 채널만 / 게시 7일 이내만 / 정렬 기준(시간당·총 조회수·최신)

### 🔤 제목 패턴
잘 나가는 영상들의 제목에서 **단어 빈도와 2단어 조합**을 셉니다.

- **분석 기준**: `시간당 조회수 상위` 또는 `총 조회수 상위 20%`
- **형용사·최상급**과 **소재 명사**를 나눠서 표시 → 제목 공식을 뽑기 좋습니다
- 단어를 **클릭**하면 그 단어가 들어간 영상만 모아 볼 수 있습니다
- 불용어(the, of, in, vs, shorts …)는 자동으로 제외됩니다

> ℹ️ 형용사 분류는 **내장 단어 목록**을 쓰는 간단한 방식입니다(품사 분석 아님).
> 목록에 없는 말은 소재 명사 쪽으로 갑니다. 코드 상단 `ADJECTIVES` 에 추가하면 됩니다.

### 📺 채널
채널을 등록하고 서로 비교합니다.

- **등록**: 주소(`youtube.com/@이름`) · 핸들(`@이름`) · 채널ID(`UC…`) 아무 형식이나 붙여넣기
- **카드 지표**: 구독자수 / 등록 후 증가분 / 최근 30일 업로드 수 / 평균·중앙값 조회수 / 최고 히트작
- **업로드 요일 × 시간대 히트맵**: 이 채널이 **언제 올리는지** 한눈에 (내 시간대 기준)
  - 어두울수록 적고 밝을수록 많습니다. 칸에 마우스를 올리면 개수가 나옵니다.
  - 맨 위에 전체 채널 합산 히트맵도 있습니다.
- **메모·태그**: 채널별 분류 메모

> `/c/이름` 이나 `/user/이름` 형식의 옛날 주소는 실패할 수 있습니다.
> (해결하려면 100유닛짜리 검색 API가 필요해서 일부러 쓰지 않습니다)
> 그럴 때는 채널 페이지에서 **@핸들** 이나 **채널ID**를 복사해 넣어주세요.

### 🙋 내 채널 — AI 분석용 CSV 만들기

내 채널의 영상 데이터를 **한 장의 CSV**로 모아 클로드에게 분석시키는 탭입니다. 경쟁 채널 목록과는 **분리**되어 저장됩니다.

**1. 등록·수집**
- 내 채널 주소(`youtube.com/@이름`) · `@이름` · 채널ID 아무 형식이나 붙여넣고 **등록**
- 업로드 목록에서 **최신 200개(50개 × 4페이지)** 를 자동 수집합니다. 쇼츠(3분 이하)와 롱폼을 **둘 다** 가져오고 유형 뱃지로 구분합니다.
- **＋ 더보기** 를 누르면 50개씩 더 가져옵니다.
- **내 채널 새로고침**(또는 상단 전체 새로고침)을 누를 때마다 내 영상들의 조회수 스냅샷이 쌓여 **시간당 조회수·증가율**이 계산됩니다. 새 업로드도 이때 자동으로 잡힙니다.

| 작업 | 쿼터 |
|---|---|
| 등록 + 최신 200개 수집 | 1 + 4 + 4 = 9유닛 |
| 더보기 (50개) | 2유닛 |
| 새로고침 (영상 n개) | 2 + ⌈n/50⌉ 유닛 (200개면 6유닛) |

**2. 스튜디오 CSV 병합 (선택)**
API 로는 볼 수 없는 **노출수·노출 클릭률·평균 시청 지속 시간·평균 조회율·구독자 증감**을 합칠 수 있습니다.

1. 유튜브 스튜디오 → **분석 → 콘텐츠** 탭 → 표 아래 **내보내기 → CSV**
2. 받은 파일을 내 채널 탭의 점선 영역에 **끌어다 놓기** (또는 클릭해서 선택)
3. 헤더가 **한국어든 영어든** 자동으로 인식합니다. 영상은 **ID(콘텐츠 열) → 정확한 제목 → 대소문자·공백을 무시한 제목** 순으로 매칭합니다.
4. 매칭에 실패한 행은 목록으로 보여주고, 드롭다운에서 어느 영상인지 직접 고르면 됩니다.

파싱에 실패하면 **몇 행·어느 컬럼**이 문제인지 한국어로 알려줍니다 (예: "6행에서 닫히지 않은 따옴표", "'콘텐츠' 또는 '동영상 제목' 컬럼을 찾지 못했습니다 — 발견된 헤더: …").

**3. 대시보드**
- 요약 카드: 총 영상 · 쇼츠/롱폼 비율 · 총 조회수 · 평균/중앙값
- **인사이트**: 조회수 상위 20% 영상의 자주 쓴 제목 단어 · 평균 길이 · 최빈 게시 요일·시간대(KST)
- 표: 제목 · 게시(KST 요일·시간) · 길이 · 조회/좋아요/댓글 · 좋아요/조회 · 댓글/조회 · 시간당 조회수 · (병합 시) 스튜디오 지표
- 필터: 쇼츠만/롱폼만 · 기간 · 정렬 7종

**4. 분석용 CSV 내보내기 (핵심)**
영상당 1행, UTF-8 BOM 으로 저장되어 한글이 깨지지 않습니다. 컬럼:

`videoId · 제목 · 제목길이 · 이모지포함여부 · 게시일 · 게시요일 · 게시시간(KST) · 게시후경과일 · 길이(초) · 유형 · 조회수 · 좋아요 · 댓글수 · 좋아요비율(%) · 댓글비율(%) · 시간당조회수 · 첫스냅샷대비증가율(%)`
(병합 시) `· 노출수 · 노출클릭률(%) · 평균시청지속시간(초) · 평균조회율(%) · 구독자증감`

버튼 아래에 **클로드에게 물어볼 추천 질문 3개**가 있습니다. 📋 복사 → 클로드에 CSV 를 첨부하고 붙여넣으세요.

### 💡 키워드 자동완성
시드 키워드에 **a~z** 를 하나씩 붙여 유튜브 검색어 자동완성을 모읍니다.
예: `ranking funniest` → `ranking funniest a` … `ranking funniest z` (총 27번)

- **YouTube Data API를 쓰지 않으므로 쿼터를 전혀 소모하지 않습니다.**
- 결과는 중복 제거 후 목록으로 표시되고 **CSV 내보내기**가 됩니다.
- 브라우저나 네트워크가 막으면 **에러 없이** 각 조합의 유튜브 검색 링크로 대체됩니다.

### ⚙️ 설정
- **API 키** 저장·삭제
- **채널당 가져올 페이지 수** (1페이지 = 최신 50개). 늘리면 쿼터도 늘어납니다
- **영상당 보관할 스냅샷 수** (기본 30개) + 새로고침 시 자동 정리
- **JSON 내보내기/가져오기**, 영상 목록 CSV, 오래된 데이터 정리, 전체 초기화

## 💾 데이터 저장

모든 데이터는 브라우저의 `localStorage`(키: `cct_v1`)에만 저장됩니다.

```js
channels[]  { id, title, handle, subs, subsFirst, subsHistory[], registeredAt,
              uploadsPlaylist, tag, thumb, lastRefresh }
videos[]    { videoId, channelId, title, publishedAt, durationSec, thumb }
snapshots   { videoId: [ { t, v, l, c } ] }     // t=시각, v=조회수, l=좋아요, c=댓글
myChannel   { channel, videos[ {videoId, title, publishedAt, durationSec, type} ], nextPageToken,
              studio: { headers[], byVideoId{ videoId: 지표 }, unmatched[], metrics[] } }   // 경쟁 채널과 분리
              // 내 영상의 스냅샷도 위 snapshots 맵을 함께 씁니다 (영상 ID 가 겹칠 일이 없음)
```

> 📌 **스냅샷만 구조가 다릅니다.** 평탄한 배열(`snapshots[]`) 대신 **videoId로 묶은 맵**을 씁니다.
> 영상 1,000개 × 스냅샷 30개 = 30,000건인데, 화면을 그릴 때마다 영상별로 전체를 훑으면
> 너무 느려지기 때문입니다(맵은 즉시 조회). **JSON 내보내기에는 평탄 배열(`snapshotsFlat`)도
> 함께 넣고, 가져오기는 두 형식을 모두 받습니다** — 다른 도구로 옮겨 쓸 때 문제없습니다.

### 용량 관리 ⭐
브라우저 저장 공간은 보통 5MB 정도입니다. 스냅샷이 쌓이면 가득 찰 수 있으니:
- **설정 탭에서 주기적으로 JSON 내보내기** (가장 중요)
- 영상당 스냅샷을 최근 N개(기본 30개)만 유지 — 새로고침 때 자동 정리
- 90일 지난 영상 일괄 삭제 버튼

저장에 실패하면 화면에 경고가 뜹니다.

## 🛠 고칠 곳 (유지보수)

모든 API 엔드포인트·파라미터·비용은 **코드 상단 `API` 상수**에 모여 있습니다.

| 상수 | 뜻 |
|---|---|
| `API.BASE`, `API.EP` | API 주소와 엔드포인트 경로 |
| `API.PART` | 각 호출의 `part` 파라미터 |
| `API.COST`, `API.DAILY_QUOTA` | 호출당 비용과 일일 한도 |
| `API.QUOTA_TZ` | 쿼터 리셋 시간대 (태평양) |
| `API.SUGGEST_URL`, `API.SUGGEST_PARAMS` | 자동완성 JSONP 설정 |
| `RULES.SHORTS_MAX_SEC` | 쇼츠 판별 기준 (기본 180초) |
| `RULES.MIN_VELOCITY_GAP_MS` | 속도 계산에 쓸 두 스냅샷의 최소 간격 (기본 10분) |
| `RULES.TOP_N`, `RULES.RECENT_DAYS` | 대시보드 표시 개수·최근 기준 |
| `STOPWORDS`, `ADJECTIVES` | 제목 분석 사전 |
| `MY.INITIAL_PAGES`, `MY.MORE_PAGES` | 내 채널 등록 시 페이지 수(4=200개)·더보기 페이지 수 |
| `STUDIO_COLS` | 스튜디오 CSV 헤더 별칭(한/영). 스튜디오가 컬럼명을 바꾸면 여기에 추가 |
| `AI_PROMPTS` | 클로드 추천 질문 문구 |

## ❓ 자주 묻는 질문

**Q. 새로고침했는데 시간당 조회수가 다 "게시 후 평균"이라고 나와요**

스냅샷이 아직 1개뿐이기 때문입니다. 몇 시간 뒤 한 번 더 새로고침하면
두 시점을 비교한 실제 증가 속도로 바뀝니다.

**Q. 영상이 50개밖에 안 모여요**

기본값이 채널당 1페이지(최신 50개)입니다. 설정 탭에서 2~3페이지로 늘릴 수 있지만
쿼터도 그만큼 늘어납니다. 쇼츠 채널은 보통 최신 50개로 충분합니다.

**Q. 롱폼 영상은 왜 안 보이나요**

3분(180초)을 넘는 영상은 트래킹하지 않습니다. 쇼츠 벤치마킹 도구라서입니다.
기준을 바꾸려면 코드 상단 `RULES.SHORTS_MAX_SEC` 을 고치세요.

**Q. "할당량을 모두 사용했습니다" 가 떠요**

오늘 10,000유닛을 다 썼습니다. **태평양 시간 자정**(한국 시간 오후 4~5시)에 초기화됩니다.
그 전까지는 새로고침이 안 됩니다. 채널 수나 페이지 수를 줄이면 다음 날부터 덜 씁니다.

**Q. 키를 넣었는데 403 오류가 나요**

키에 **HTTP 리퍼러 제한**이 걸려 있으면 파일(`file://`)에서 열 때 막힙니다.
Google Cloud Console에서 그 키의 **애플리케이션 제한을 "없음"** 으로 바꾸거나 IP 제한으로 변경하세요.
(대신 키가 새어 나가지 않게 조심하세요)

**Q. 자동완성이 안 되고 검색 링크만 나와요**

유튜브 자동완성은 공식 API가 아니라 JSONP 방식이라, 브라우저·확장프로그램·네트워크가
막으면 동작하지 않습니다. 그럴 때 쓰라고 검색 링크 폴백을 넣어 뒀습니다.
링크를 눌러 유튜브 검색창에 넣으면 자동완성이 바로 보입니다.

**Q. 스튜디오 CSV 를 넣었는데 대부분 "미매칭"이에요**
스튜디오 표의 **콘텐츠** 열(영상 ID)이 있으면 거의 다 맞습니다. 제목만 있는 경우 스튜디오에서 제목을 바꿨거나 이모지·특수문자가 다르면 못 맞출 수 있습니다. 미매칭 목록의 드롭다운에서 직접 골라주세요. 또 **내 채널 탭에 아직 수집되지 않은 영상**은 매칭할 대상이 없으니, 더보기로 먼저 가져오세요.

**Q. 스튜디오 CSV 헤더가 인식되지 않아요**
콘솔(F12)에 "인식하지 못한 스튜디오 컬럼" 이 찍힙니다. 코드 상단 `STUDIO_COLS` 의 `keys` 에 그 헤더(소문자·공백/괄호/% 제거한 형태)를 추가하면 됩니다.

**Q. 내 채널 영상이 급상승 탭에 안 나와요**
의도된 동작입니다. 내 채널은 경쟁 채널과 분리되어 있어 급상승·제목 패턴·채널 비교에는 섞이지 않습니다.

**Q. 다른 컴퓨터로 옮기려면?**

설정 탭 → **JSON 내보내기** → 새 컴퓨터에서 `tracker.html` 열고 **가져오기**.
API 키는 백업에 들어가지 않으니 새 기기에서 다시 입력하세요.
